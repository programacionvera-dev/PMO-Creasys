# Agentes PMO Creasys

Este repositorio contiene scripts y herramientas para la gestión de proyectos PMO.

## Scripts Disponibles

| Script | Descripción |
|--------|-------------|
| `generar_reporte_nevasa.py` | Genera reporte ejecutivo en Excel |
| `generar_plantillascorreo.py` | Genera plantillas HTML para correos |
| `generar_datos_powerbi.py` | Genera datos pre-calculados para Power BI |

## Configuración

Las rutas están centralizadas en `scripts/config/rutas.py`.

## Documentación

Ver `docs/` para documentación detallada.
